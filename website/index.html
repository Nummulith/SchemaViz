SchemaViz

General overview

SchemaViz is the DaC (Diagram as Code) tool.

It generates diagrams that visually describe relationships between objects based on two key input sources: Metadata and Data.

Metadata defines the object classes, including their fields and attributes, while Data describes instances of these objects and their specific values. Together, these inputs enable the generation of clear, meaningful diagrams to represent object hierarchies, associations, and more.

This approach allows for dynamic creation of complex object relationship diagrams easily

Usage

The Metadata input is provided on the Metadata tab, while the Data input is entered on the Data tab. The resulting diagram is generated on the Result tab by clicking the "Generate Diagram" button.

Capabilities

By clicking the buttons, predefined example values will be loaded into the Metadata and Data tabs, and the view will switch to the Result tab, generating the corresponding diagram. You can review the example data and metadata on their respective tabs if needed.

Metadata structure

The Metadata structure is represented as YAML and has a three-level hierarchy:

  • Classes
  • Fields
  • Field Properties

Classes

These are the object classes that are defined in the metadata and will have corresponding data instances in the Data section

Fields

These are the fields of the object classes that are outlined in the metadata. Each field will have corresponding values in the Data section, representing the properties or attributes of the objects.

There are predefined fields:

  • Color: Defines the color of the object.
  • Draw: Specifies an array of elements that determine the object's display. Possible elements:
    • ID: Object identifier.
    • VIEW: Primary representation.
    • EXT: Extended representation.
    • CLASS: Name of the object's class.

Field Properties

Field properties can be:

  • Value: Indicates a constant value.
  • Role: Specifies the role of the field, which can be:
    • OWNER: Owner of subordinate objects.
    • LIST_NAME: Name of a list.
    • LIST_ITEM: Identifier within a list.
    • ID: Object identifier.
    • VIEW: Primary representation.
    • EXT: Extended representation.
    • LINK: Outgoing link.
    • LINK_IN: Incoming link.
  • Type: Specifies the class name as a type reference, indicating that the field is a link.

Example


            Score:
                Color: BLUE_DARK
                Draw: [VIEW]
                Id:
                    Role: ID
                Name:
                    Role: VIEW

Data structure

Data structure is represented as YAML and has a two-level hierarchy.

It has an additional array level at the top for convenience in structuring the data.

The layers are:

  • Classes: Classes of objects.
  • Object fields: Objects (as the sets of it's fields).

Example


            - Score:
                - Id: 001
                  Name: 'This score'
